# OptionsWindowShade

Two subtle buttons on the title bar of the Options window (`Esc` > Options):

- **Shade** — collapses the window to just its title bar so you can see the thing you are configuring. Click again to bring it back.
- **Lock / Unlock** — unlocked, drag the title bar to move the window out of the way.

Nothing is remembered on purpose: when the window is closed it reopens centered, full size and locked, exactly as Blizzard ships it.

## Keybinds

Two optional keybinds (Options > Keybindings > Options Window Shade), no defaults, only active while the Options window is open:
shade/unshade, lock/unlock. The button tooltips show the current key.

## Slash

`/ows` (or `/optionswindowshade`): `shade`, `lock`, `help`.

Supports WoW Forever and Classic Era. No SavedVariables, no libraries.
